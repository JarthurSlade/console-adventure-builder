# Console Adventure Builder

## About the Project

Console Adventure Builder is a simple text adventure editor I created to make branching story games originally so I could easily make a game for my fiance. It allows users to write scenes, add choices, and connect those choices to different parts of a story.

The goal of this project was to create an easy way to organize text adventures without having to manually write all the C++ code for each scene.

## Features

- Create, edit, duplicate, and delete scenes
- Write story descriptions and add ASCII artwork
- Add choices that lead to different scenes
- Organize scenes into folders
- Preview scenes while editing
- Save and load projects using JSON files
- Export a completed adventure as a C++ program

## Technologies Used

- HTML
- CSS
- JavaScript
- C++ (generated game output)
- JSON (saving and loading projects)

## How to Use

1. Download the `index.html` file from this repository.
2. Open the file in a web browser.
3. Click **Add** to create a new scene.
4. Enter the scene text and add choices.
5. Connect each choice to another scene.
6. Use the preview to see how the scene will appear.
7. Save your project or export it as a C++ file.

The exported C++ program can be compiled and run using a C++ compiler.

## What I Learned

Working on this project helped me practice JavaScript, HTML, and CSS while learning more about how to organize information between different scenes. I also gained experience with saving data using JSON and generating C++ code from user input.

One of the challenges was making sure that choices connected to the correct scenes, especially when scenes were added or deleted. This project helped me better understand how different parts of a program work together.
